Why there are no machines in the list?

Please check if your GitHub repository is fully and correctly set up.

Virtual machines are usually started within 1..2 hours after repository setup is completed.

Note that virtual machines are not started for students who didn't show any activity recently.

To solve it, just add one commit to your repository to show you're still with us -- and your machines will soon be started automatically.

I want to reset machines!

Create an issue in your GitHub repository with a title containing the word DESTROY.

Our bot will recreate all your virtual machines within a few hours.

I have completed lab 3 tasks, but there is no second machine. Why?

There is little use of this machine before that anyway.
